版本：**v0.1.0 早期预览版**。文档适用于 Windows 10/11、Linux 和 macOS。

> **建议先使用 Discord 官方个人数据包完成第一次归档。** 可选在线扫描器依赖非官方的普通用户账号自动化机制，存在违反 Discord 平台规则而导致账号受限的风险。完整说明见 [第八章](#八安全与平台限制)。

## 一、项目用途与能力范围

Discord Personal Archive 是运行在你自己电脑上的个人知识归档工具，而不是 Discord 机器人或云端托管服务。

它由四个部分组成：

| 组件 | 作用 | 是否必需 |
| --- | --- | --- |
| FastAPI 本地服务 | 数据导入、搜索接口、AI 任务、文件导出 | 必需 |
| SQLite 数据库 | 保存消息与 AI 摘要，按消息 ID 去重 | 必需，自动创建 |
| Vue 3 GUI | 浏览归档、筛选、配置 AI、查看报告 | 必需，已预构建 |
| Chrome 只读扩展 | 在明确同意风险后尝试在线扫描本人历史发言 | 可选、不推荐作为首选 |

可处理的消息来源包括服务器文字频道、帖子、单人私信、群组私信，以及 Discord 官方包实际包含的其他消息文件。归档的是**你自己发过的消息**，不是其他成员的聊天全文。

每条归档记录尽可能保留消息 ID、来源频道、时间、正文、附件链接及导出中可用的额外信息。是否有频道名称、帖子类型、置顶标记等，取决于 Discord 提供的元数据。

## 二、安装和启动

### 2.1 系统要求

- Windows 10/11、Linux 或 macOS。
- Python **3.11+**；首次安装需要访问 Python 包索引。
- 支持现代网页的浏览器（推荐 Chrome 或 Edge）。
- 首次使用不需要 Node.js：发布包包含 `frontend/dist/`。
- 如果使用本地 AI，还需要另外安装 [Ollama](https://ollama.com/) 及对应模型。

### 2.2 Windows（推荐）

1. 下载仓库 ZIP，或使用 Git 克隆仓库。
2. 将整个项目解压到有读写权限的位置，例如 `D:\Tools\Discord-Personal-Archive`。**不要只解压 `start.bat` 一个文件。**
3. 安装 Python 3.11 或更高版本，并确认在 PowerShell 中可以执行：

   ```powershell
   py -3 --version
   ```

4. 双击根目录的 `start.bat`。首次启动会建立 `.venv` 虚拟环境并安装依赖。
5. 浏览器应自动打开 `http://127.0.0.1:8765`。如果没有自动打开，手动输入该地址。
6. **关闭启动窗口**就会停止本地服务。再次使用时重新双击启动脚本。

如遇安装失败，请查看脚本窗口里的报错，并确认 `py` 命令有效、网络可访问 Python 包源。

### 2.3 Linux / macOS

在项目根目录运行：

```bash
python3 --version
sh start.sh
```

首次会创建虚拟环境并安装依赖；服务地址同样是 `http://127.0.0.1:8765`。如需直接运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

### 2.4 数据存放在哪里？

默认消息数据库：`data/archive.sqlite`。本地服务使用 SQLite WAL 模式，因此运行期间也可能出现 `archive.sqlite-wal` 等文件。

**备份时先正常关闭服务，再复制整个 `data/` 目录**，避免复制到未落盘的事务。你也可以设置 `DPA_DATA_DIR` 环境变量更改数据目录。不要把数据目录推送到 GitHub。

## 三、导入 Discord 历史消息（首选）

### 3.1 获取官方数据包

1. 打开 Discord。
2. 进入 **用户设置 → 数据与隐私（Data & Privacy）**。
3. 找到申请数据副本（Request Data / Request My Data），勾选需要的数据类型，确保包含消息。
4. 等待 Discord 将下载链接发送到账号邮箱；处理可能需要**最多 30 天**。
5. 下载包含 `messages` 文件夹的 ZIP。**无需手动解压，不要上传到陌生在线解析站点。**

官方说明：[Your Discord Data Package](https://support.discord.com/hc/en-us/articles/360004957991-Your-Discord-Data-Package) 和 [Requesting a Copy of your Data](https://support.discord.com/hc/en-us/articles/360004027692-Requesting-a-Copy-of-your-Data)。

### 3.2 在本地 GUI 导入

1. 启动 Discord Personal Archive。
2. 左侧打开「**数据导入**」。
3. 选择 Discord 官方 ZIP，或者拖放到文件选择区域。
4. 等待提示「新增 N 条、更新 N 条、发现 N 个来源」。
5. 打开「**总览**」检查消息量，再到「**消息浏览**」搜索近期一条你确实发过的消息。

导入过程只提取数据包的 `messages` 内容，不读取账号、支付等其他目录；ZIP 文件不会被展开为任意路径。

支持新版 JSON 与旧版 CSV 格式。也可导入原 Discord 清理器导出的 `dsc-preview-v1` 预览 JSON（包括这类 JSON 的 ZIP 包）。

### 3.3 大文件与重复导入

当前上传限制：

- 单次 ZIP 上传不超过 **250 MB**。
- ZIP 内所有文件解压后总大小不超过 **1 GB**。
- 单个归档条目不超过 **128 MB**，文件条目总数不超过 **20,000**。

遇到超限时请不要反复重试；当前版本没有多 ZIP 自动分卷导入功能，可以在保留 Discord 消息目录结构的前提下整理较小的导入包。

同一消息由 Discord 消息 ID 去重。再次导入可更新已有记录，不会简单地重复增加消息数量。不同频道出现相同 ID 时会拒绝导入，以保护数据一致性。

### 3.4 导入后看不到某些对话？

- **其他成员发言**：官方个人数据包不是完整双向聊天记录，不能凭你的消息还原别人回复。
- **删除过的消息**：官方包通常不包含已删除消息。
- **服务器/频道已无法访问**：可能影响包里的可用元数据。
- **附件**：此版本保存附件 URL，不会自动下载原文件。链接未来可能过期。
- **类型显示为“待识别来源”**：原始导出缺少对应的频道元信息，并不代表消息导入失败。

## 四、使用 Vue 图形界面

当前 v0.1.0 **GUI 文案为中文**；本仓库文档支持中文 / English 互相切换。后续可为 GUI 增加完整的界面多语言支持。

| 页面 | 适合做什么 |
| --- | --- |
| **总览** | 查看消息数量、频道数量、类型分布、最近摘要 |
| **消息浏览** | 从左侧频道或私信列表筛选，跨频道按正文、频道名、消息 ID 搜索 |
| **知识摘要** | 阅读已生成的 AI 文档，按 Markdown 下载 |
| **AI 工作台** | 按全库或单一来源选择模型，执行分批总结 |
| **数据导入** | 导入 ZIP/JSON，查看扩展配对信息 |

推荐的第一次体验：

1. 导入小规模个人数据包。
2. 在「消息浏览」输入项目关键词（如你曾讨论过的技术、活动名称）。
3. 点击某个来源，将搜索范围限定到一条频道或私信。
4. 找到需要的范围后转到「AI 工作台」生成摘要。
5. 在「知识摘要」检查内容和引用的消息 ID。

**提醒：** 搜索结果只代表已经导入本地数据库的内容；并非实时搜索整个 Discord。

## 五、AI 总结：Ollama 与云端 API

### 5.1 工作方式

工具会读取所选范围内**最新的最多 20,000 条归档消息**，按批次组织带时间和消息 ID 的文本，先提取主题、决定、待办及重要资源，再多轮合并为知识摘要。

- 没有消息的频道不能生成摘要。
- 单条特别长的内容会截取前部参与分析，不代表逐字全文分析。
- 摘要质量取决于模型能力及上下文完整度，请按消息 ID 回查重要结论。
- v0.1.0 每次只运行一个 AI 任务；任务重启后不能从中断处恢复。
- 分析由用户在 GUI 中点击「**生成知识摘要**」启动；当前不具备无人值守的定时自动总结。

### 5.2 本地 Ollama：消息无需发往云端

1. 安装并启动 [Ollama](https://ollama.com/)。
2. 从终端下载你想使用的模型，例如：

   ```bash
   ollama pull qwen3:4b
   ```

3. 确保 Ollama 服务正在运行，默认地址是 `http://127.0.0.1:11434`。某些系统需手动运行 `ollama serve`。
4. 在「AI 工作台」选择「**本地 Ollama**」。
5. 设置：服务端点 `http://127.0.0.1:11434`；模型名称 `qwen3:4b`。
6. 选择「全部消息」或某个「频道 / 私信」，填写可选标题，然后点击「生成知识摘要」。
7. 等待任务进度变为完成，转到「知识摘要」阅读及导出。

模型名称必须与你在本机实际安装的模型一致。生成质量、速度和内存需求会受硬件与模型影响。

### 5.3 云端 OpenAI 兼容 API

1. 在「AI 工作台」选择「**兼容云端 API**」。
2. 填写 API Base URL。标准示例：`https://api.openai.com/v1`。
3. 填写提供商支持的模型 ID 及有效 API Key。
4. 选择要总结的消息范围，再主动启动任务。

**注意：** 选择云端后，被分析的消息正文、时间和相关标识将发送给**你填写的 API 地址**，其隐私处理与收费规则由该提供商决定。请勿随意使用来路不明的代理接口。

此版本采用 OpenAI **Chat Completions** 兼容结构：`POST /chat/completions`。并非所有宣称兼容 OpenAI 的服务都支持相同请求参数。云端端点必须使用 HTTPS；只有回环地址上的本地兼容服务可使用 HTTP。

API Key 只用于当前任务，不写入 SQLite 或配置文件；请仍避免把密钥截图、日志或消息复制到公共位置。

### 5.4 导出总结

打开「知识摘要」，选中一份报告，点击 **Markdown** 下载。摘要包含模型生成的主题、决定、待办与资源；消息 ID 可用于溯源，但 AI 可能遗漏或误读原文。

## 六、可选在线只读扫描（账号风险）

**这是实验性兼容功能，不是官方推荐路线。** Discord 对普通账号自动化的限制不因“只读取数据”而消失。请在充分理解风险后自行决定是否使用。

### 6.1 安装 Chrome 扩展

1. 保持本地服务运行。
2. Chrome 地址栏打开 `chrome://extensions`，打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目里的整个 `extension/` 文件夹。
4. 在浏览器中打开 **https://discord.com/channels/** 并登录自己的账号，进入具体频道、帖子或私信。
5. 在本地 GUI「数据导入」页面复制配对码。
6. 点击扩展图标，将配对码粘贴到扩展界面。

此配对码用于让扩展向**你本机**的归档服务提交数据，服务重启后会变化。它不是 Discord 登录令牌。

### 6.2 设置扫描范围

1. 点击扩展中的「使用当前频道」之类的自动填入按钮，核对服务器 ID 与频道 / 帖子 ID。
2. 若扫描特定私信，必须进入那一条具体的私信会话。
3. 选择起止时间和最多采集的本人消息条数（每轮 **1–20,000 条**）。
4. 阅读并勾选账号风险提示。
5. 手动点击开始，观察已扫描条数、本人消息数和本地保存数量。
6. 如有异常立即停止；完成后在本地 GUI 验证对应来源是否出现。

目前实现两种路径：

- **指定频道 / 帖子 / 私信：** 按频道分页读取，再过滤保留当前账号作者的消息。
- **指定整个服务器：** 不填频道 ID，调用服务端消息搜索接口按作者筛选。它依赖 Discord 的搜索索引，**可能漏掉未索引或无权限的内容**。

扩展对 Discord 仅调用 GET 读取接口；**不包含发送、删除、编辑消息的操作**。但是它会使用登录网页里的用户令牌，而这种自动化方式违反 Discord self-bot 规则，仍可能导致账号风险。

### 6.3 完整性与限速

- Discord 的权限、搜索索引、接口变更、HTTP 429 限速可能中止或影响采集。
- Manifest V3 后台工作进程可能休眠；请保持标签页和扫描弹窗打开。
- 目前没有跨浏览器重启的断点恢复；可重新扫描相同范围，SQLite 会按 ID 去重。
- 扩展不会将 Discord Token 发给本地服务；仅发送整理后的本人消息、频道元数据及本地配对码。
- **开发测试使用了模拟浏览器和模拟 API，尚未用真实 Discord 账号完成在线验收。**

## 七、数据维护、更新与故障排查

### 7.1 安全备份

先关闭服务，再复制 `data/` 到安全位置。恢复时在服务停止状态下放回相同目录。建议对备份进行磁盘加密，尤其当消息含有私信、邀请链接、电子邮件、内部资料时。

更新代码时保留 `data/`；不要把旧数据库覆盖到一个正在运行的服务实例。

### 7.2 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 启动窗口一闪而过 | 在终端运行 `start.bat` 查看错误；确认 Python/py 命令与安装网络 |
| 页面显示 Vue 尚未构建 | 安装 Node.js 22，在 `frontend/` 执行 `npm ci`、`npm run build` |
| 无法打开 `127.0.0.1:8765` | 检查启动窗口是否还在；端口 8765 是否被其他程序占用 |
| ZIP 导入失败 | 确认是 Discord 官方包，含 `messages/`，并检查上传/解压大小限制 |
| 摘要一直失败 | 检查 Ollama 是否在运行、模型名称是否存在、API Base URL 是否正确 |
| 云端返回 401/429 | 检查提供商密钥、额度、速率与模型权限；此项目不负责提供额度 |
| 扩展提示配对失败 | 服务是否启动、配对码是否来自当前服务实例、扩展是否仍有效 |
| 频道消息少于预期 | 官方数据包只包含本人消息；在线模式还受权限和搜索索引影响 |
| 附件打不开 | 此版仅存链接；Discord 原始附件 URL 可能已失效 |

### 7.3 高级本地开发

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python tests/integration_smoke.py
node tests/test_extension.mjs
```

修改 Vue 前端后执行：

```bash
cd frontend
npm ci
npm run build
```

集成测试会启动临时本地服务与模拟 Ollama / OpenAI 兼容接口，**不会联系真实 Discord 或使用付费云端凭据**。

## 八、安全与平台限制

1. **平台协议：** [Discord 官方明文禁止 self-bots](https://support.discord.com/hc/en-us/articles/115002192352-Automated-User-Accounts-Self-Bots)。只读在线扩展不是官方许可，存在账号封禁风险。绝不要把此工具描述为“Discord 授权采集器”。
2. **可访问范围：** 工具只打算保存当前账号自己发送的消息；不绕过频道权限，不获取其他人私信记录，也不保证完整历史。
3. **本地接口：** 仅监听 `127.0.0.1:8765`，有来源校验与扩展配对码，但它是单人本地应用，**没有公网鉴权系统**。不要端口转发、反向代理或对局域网开放。
4. **凭据：** 不将用户 Token 或 AI Key 持久化保存；仍应防止浏览器扩展、操作系统恶意软件或截图泄露敏感信息。
5. **云端 AI：** 发送到外部模型的内容脱离本机控制；使用前应确认自己有权处理这些消息以及供应商的隐私政策。
6. **外部内容：** Discord 发言可能包含提示词注入。总结器将其作为待分析数据，但不能保证模型不会被误导；重要决定必须由人核实。
7. **数据库：** SQLite 文件和导出的 Markdown 报告可能含敏感个人资料，请妥善存储、备份与删除；`data/` 已列入 `.gitignore`。
8. **没有实现：** 消息删除/编辑/发送、附件文件下载、多人登录、定时无人值守采集、断点续扫、完整双向聊天还原、真实账号在线兼容性保证。

如发现安全问题，请不要在公开 Issue 里粘贴真实用户 Token、API Key、完整私信或私人数据包。

## 九、技术实现与许可

- **后端：** Python、FastAPI、SQLite；消息导入后按 ID 去重，AI 任务在后台执行。
- **前端：** Vue 3 + Vite，预构建页面由本地服务提供。
- **可选浏览器扩展：** Chrome Manifest V3；Discord 侧只读，归档通过本地配对接口同步。
- **许可：** [MIT License](../LICENSE)。

GitHub Actions 会验证 Python 单元测试、本地端到端测试、扩展模拟采集和 Vue 生产构建。**自动化测试通过不等于 Discord 官方认可，也不等于实账号扫描安全。**
